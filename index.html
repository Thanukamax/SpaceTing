16,000 Celestial Bodies in a Single Draw Call

Rendering thousands of independent 3D meshes crushes frame rates due to CPU draw-call dispatch overhead. To achieve 60 FPS across both desktop and mobile viewports, we collapsed the entire planetary system into point sprite billboards, calculating true 3D spherical volumes and Lambertian illumination entirely within the GLSL fragment stage.

core_raymarch.frag
// 1. Reconstruct spherical surface normal from 2D coordinates
float z = sqrt(max(0.0, rSphere * rSphere - dist * dist));
vec3 norm = normalize(vec3(coord.x, -coord.y, z));
// 2. Single-pass Lambertian light incidence with forward scattering
float NdotL = max(0.0, dot(norm, normalize(uSunDirection)));
